Requisitos do Sistema

Infraestrutura

  • Conta ativa na Supabase (Free tier suportado)
  • Acesso ao editor SQL da Supabase
  • Capacidade de criar Storage Buckets públicos e privados

Cliente & Dev

  • Node.js 20+ (se executado localmente)
  • Navegador moderno (Chrome, Edge ou Safari)
  • Dispositivo móvel com iOS 15+ ou Android 12+ (para app)

Guia de Implantação

1

Configuração Inicial Supabase

Acesse supabase.com, crie uma conta e inicie um novo projeto. Escolha uma região próxima aos seus usuários e defina uma senha forte para o banco de dados.

Importante: Aguarde até que o banco de dados esteja totalmente provisionado antes de prosseguir.

2

Execução do Esquema (SQL)

No painel lateral da Supabase, clique em SQL Editor, crie uma nova query chamada "Setup ApontAuto" e cole o conteúdo do script SQL completo fornecido neste manual.

Ir para SQL Completo
3

Configuração do Storage

Vá em Storage e crie os buckets necessários (ex: evidencias, checklist-fotos). Certifique-se de aplicar as policies de RLS para permitir uploads de usuários autenticados.

Solução de Problemas

Erro: "Policy not found" ao fazer upload

Causa: O bucket do Storage não possui policies de SELECT/INSERT habilitadas para authenticated.

Solução: Adicione policies no painel Supabase Storage.

Erro: "Invalid JWT" no frontend

Causa: Chaves de ambiente incorretas ou projeto Supabase pausado.

Solução: Verifique o arquivo .env e o status do projeto.

FAQ

O sistema funciona offline?

Sim. O ApontAuto utiliza IndexedDB para cache local e sincronização automática quando a rede retorna.

Como integrar com Power BI?

Utilize a string de conexão direta do PostgreSQL fornecida na aba Database Settings da Supabase.
